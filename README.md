# Психология школы в подходах Альфреда Адлера и Карла Густава Юнга

Комплект материалов для студенческого доклада по психологии: текст доклада,
тезисы для выступления и презентация на 10 слайдов.

**Тема №8.** Формулировка для доклада: «Психология школы в подходах Альфреда
Адлера и Карла Густава Юнга». Предмет — сравнение индивидуальной психологии
А. Адлера и аналитической психологии К. Г. Юнга во взглядах на школу, ребёнка,
учителя и обучение.

**Автор:** Сабадаш Павел Андреевич, группа ИС-24, РКСИ, 2026.

## Как открыть презентацию

Просто откройте файл в браузере:

```bash
open presentation/index.html          # macOS
xdg-open presentation/index.html      # Linux
start presentation\index.html         # Windows
```

Либо запустите локальный сервер (если удобнее):

```bash
python3 -m http.server 12000 --directory presentation
# затем откройте http://localhost:12000/
```

### Управление

- `→`, `Space`, `PageDown` — следующий слайд;
- `←`, `PageUp` — предыдущий слайд;
- `Home` / `End` — первый / последний слайд;
- `F` — полный экран;
- клик по правой части экрана — вперёд, по левой — назад;
- адрес вида `index.html#7` открывает конкретный слайд.

### PowerPoint-версия

Файл `presentation/psihologia_shkoly_adler_jung.pptx` открывается в PowerPoint,
LibreOffice Impress, Google Slides и Keynote. Формат 16:9 (33,87 × 19,05 см).
Весь текст — настоящие текстовые блоки, а не картинки: можно править прямо в
редакторе. Шрифты: Georgia (заголовки, цитаты) и Segoe UI (тело); на Windows и
macOS они есть, на Linux подставятся близкие аналоги.

### Печать и PDF

Презентация печатается корректно: `Ctrl+P` → «Сохранить как PDF» — каждый слайд
на отдельной странице (в стилях есть блок `@media print`).

## Как пересобрать документы

Требуется Python 3 и библиотека `python-docx`:

```bash
pip install python-docx
python3 tools/build_docs.py      # создаст report/report.docx и report/theses.docx
```

Презентация `presentation/index.html` — самостоятельный файл, сборка не нужна:
открывается в любом браузере и правится как обычный HTML/CSS/JS.

Если предпочитаете pandoc, тот же доклад можно собрать из Markdown:

```bash
pandoc report.md -o report/report.docx --reference-doc=reference.docx
```

(В репозитории используется собственный генератор `tools/build_docs.py`, потому
что он точно задаёт поля, отступы и интервалы.)

## Презентация: слайды

1. Титульный.
2. Почему школа стала объектом психологии в XX веке.
3. Адлер: чувство неполноценности и компенсация.
4. Адлер: социальный интерес и школьная практика.
5. Юнг: коллективное бессознательное и архетипы.
6. Юнг: психологические типы и обучение.
7. Юнг: учитель как архетип и индивидуация.
8. Общее и различное (таблица).
9. Значение для современной школы.
10. Выводы и источники.

### Дизайн

Рассчитан на светлый кабинет, тёплая палитра:

| Роль | Цвет |
|------|------|
| фон | `#FDFCF8` — тёплый off-white, не слепит на проекторе |
| основной текст | `#1C1917` — тёплый чёрный |
| Адлер | `#B45309` — жжёная охра |
| Юнг | `#4C3575` — глубокий сливовый |
| линии | `#E5E1D8` |

Заголовки и акцентные цитаты набраны Georgia (serif), тело — system-ui. Это
даёт «журнальный» вид и контраст между заголовком и текстом. Композиция у
каждого слайда своя: асимметричная вёрстка, тонкие линии вместо карточек,
разные пропорции колонок. Отступы — 80 px по горизонтали и 64 px по вертикали.
Анимаций нет: показ слайдов мгновенный. Контраст текста проверен: минимум
4.9 : 1 на светлом фоне.
